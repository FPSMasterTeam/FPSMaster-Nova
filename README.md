# FPSMaster Nova
## 如何部署开发环境

### UI
1. 安装Node.js
2. 克隆仓库
3. 进入 ui 目录
4. 运行`npm install`
5. 运行`npm run dev`

### Mod
1. 使用 IntelliJ IDEA 打开项目
2. Link `build.gradle.kts`
3. 运行客户端 `gradlew runClient`

### 特殊说明：
仅支持Windows、Linux（未测试）、MacOS（未测试）

不支持 Android

GPU渲染加速仅支持 Nvidia、AMD GPUs，不支持 Intel GPUs
