# Windows CEF 消息泵与游戏帧率

空闲 WebView 下每帧从游戏渲染线程同步调用 CEF 消息泵，可能按系统定时量子阻塞并显著降低帧率；浏览器动画活跃时问题反而暂时消失。

## 正确方向

- 使用 CEF 调度请求驱动专用消息泵线程，而不是渲染线程每帧裸调用。
- CPU 帧通过线程安全双缓冲传给渲染线程上传。
- 加速共享句柄必须在回调有效期内导入；不能延后使用已由 CEF 回收的句柄。
- 共享纹理所有权、同步和删除责任必须唯一，包装外部纹理时不得重复释放。
- 新版 Minecraft 渲染路径需显式把加速纹理包装为可绘制 GPU 资源，否则“启用加速”不代表存在显示通路。
- 零拷贝路径必须在 Windows 实机验证共享上下文、跨线程同步、颜色和尺寸；其他平台保持安全回退。
