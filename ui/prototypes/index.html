FPSMaster Nova · 融合原型

与 Edge 共用令牌（靛蓝 accent、玻璃面板、Lucide 矢量图标、iOS 开关）。Nova 保留自己的版式：左侧字标主菜单、可折叠图标轨、音乐与配置嵌在 ClickGUI 内。
主界面

客户端设置
可折叠图标轨、紧凑模块行、两列设置
音乐
嵌在 ClickGUI 内：正在播放 + 每日推荐
配置文件
嵌在客户端页：当前配置 + 档案网格
OOBE
单页三偏好卡：匿名数据 / 安全 / 背景
和 Edge 的分工
共用：accent #5965F1、玻璃材质、圆角令牌、矢量图标、开关 / 滑杆 / 分段控件、左侧 accent 亮边。
Nova 独有：左侧字标主菜单（Edge 是底部磁贴坞）、图标轨可折叠（CEF 能动效）、音乐与配置是 ClickGUI 内页而不是独立屏幕、OOBE 单页三卡（Edge 是分步导轨）。
毛玻璃：Nova 走 CEF backdrop-filter，默认可开；Edge 用 Kawase，默认关。
